# dsh-injection-tune

长会话里，模型每走一步都要把工具清单、项目说明、运行时状态重新发一遍，其中大半内容上一步刚发过。这个插件给这些固定开销做减法：哪些内容该裁短、哪些干脆不下发，都可以在设置页逐项控制。裁剪口径、默认值和逐版装机实测由我把关，实现交给 AI 协作。

DSH 宿主插件，用于压低每个请求步的注入体积。设置页分「自动精简」「注入名单」两类共 6 个模块，各自独立。自动精简里的三项外部注入拦截默认开启，新增的模型切换提示拦截默认关闭，其余改写默认关闭；两扇注入名单默认关闭（名单保留但不生效）。因此加载后不会改变工具与技能的可用性。

## 背景

DSH 的 agent 每一步都会重新组装请求：runtime-context 快照、技能目录、项目指令、工具 schema 全量重发。长会话里这些固定开销占每步输入的一半以上，而其中大部分内容在步与步之间并没有变化。本插件在请求组装和每步改写两个位置分别做削减。

## 设置页

面板位于 设置 → 内置插件 → 注入调优。界面统一用功能名，不再暴露内部代号：历史上「AI-4」同时指 ACP 拦截与工具门，出现顺序也乱，两扇名单默认整屏展开，页面又长又难找。

现在按用途分成 6 张卡片，可逐张展开收起，顶部也能一键全展开/全折叠，默认全折叠，一屏只看得到 6 行标题；折叠时标题旁直接显示「x/y 项启用」这类状态。卡片收起只是隐藏、不卸载，名单数据和刚勾的选项都留着。折叠状态存在浏览器 localStorage 里，不写进插件配置。

## 功能

能调的几类事，都在设置页逐项开关：

固定内容做减法。每步重发但没变化的运行时快照、技能目录、项目指令可以压缩：运行时快照只折叠同一条消息内部重复的段落，技能目录改成只列新增和描述有变化的条目，项目指令按 `##` 分节、只保留开头两节，其余折叠成一行读取指引。工具说明也能按字符预算裁剪，硬纪律句（必须/禁止/拒绝）优先保留，每条可单独豁免，并提供「精简预览 / 原文对照」两栏按需展开核对。

外部注入拦截。按来源剔除几类宿主自动追加的段落，包括会话中途换模型时的 `[model changed: …]` 提示。后者还会做一层历史投影，让开启之前已经落盘的旧提示也不再随请求重发；会话日志本身不改写，轨迹里仍看得到。

工具与技能注入名单。按注册来源分框列出全部工具和技能，取消勾选即不再下发；工具门和技能门的名单、预算、开关都落在 `~/.dsh/injection-tune/` 下，跨重启保留，卸载即回透传。技能隐藏是投影式过滤，只影响面向 agent 的查询，设置页与技能管理器仍看得到全部、随时可恢复；用户显式输入 `/技能名` 属于人直接点名，故意不拦。

## 配置

配置键、默认值与 volatile 语义见设置页和 `lib/config.js`。两扇门的开关与名单在面板里操作，不占配置键。

## 安装

```bash
dsh plugin --profile web install github:JiewiW/dsh-injection-tune#main
```

## 测试

```bash
node --test
```
